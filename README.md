# 🌐 Responsive Landing Page

A modern and responsive landing page built using **HTML, CSS, and JavaScript**.  
This project includes a sticky navigation bar, smooth scrolling, mobile menu toggle, animations, and scroll-based reveal effects.

---

## 🚀 Features

- 📱 Fully responsive design (desktop & mobile)
- 🧭 Sticky navigation bar
- 🍔 Mobile-friendly hamburger menu
- 🎯 Smooth scrolling navigation
- ✨ Scroll reveal animations
- 🎨 Hover effects and button animations
- ⚡ Clean and simple UI layout

---

## 🛠️ Technologies Used

- **HTML5** – Page structure
- **CSS3** – Styling, responsiveness, animations
- **JavaScript (ES6)** – Interactivity & DOM manipulation
